Git branching, merging and rebasing, explained by watching it work

Git keeps your work as a chain of snapshots called commits. These pages show that chain as a picture. Pick a topic, press Play to watch it happen, or click the commands yourself. A soft voice and gentle sounds explain each step.

CommandWhat it doesUse it whenBe careful
git switch <branch>
git checkout <branch>		Moves HEAD to another branchYou want to work on a different branchswitch only switches. checkout has other jobs too.
git mergeJoins another branch into yoursA feature is finished. Safe on shared branches.Conflicts need a human decision
git rebaseReplays your commits on top of another branchTidying your own private branchRewrites history. Don’t rebase shared commits.
git cherry-pickCopies one commit onto your branchOne fix must move without the restThe copy gets a new ID
Fixing a conflictEdit, git add, then git commitGit says CONFLICT during a mergeStuck? git merge --abort goes back

The commits and IDs here are made up for learning. git switch needs Git 2.23 or newer. Voice uses your browser’s built-in speech, and sound starts after your first click.
